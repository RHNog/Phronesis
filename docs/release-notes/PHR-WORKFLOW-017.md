# PHR-WORKFLOW-017 — Ongoing Event Team Access

An active Event Ledger now includes an `Event team` control for adding people after the event has opened.

Approved accounts can be sent to People & access, approved or invited with an `Event Ledger only` preset, or given Ledger access in one action without losing their other modules. The permission works on the next request and remains until an administrator changes it.

Temporary workers can receive a single-use account-free code scoped only to `Event Ledger · Operate` for the current event. That access ends at the configured time, on revocation, or immediately when the event closes.

Only a permanently signed-in Phronesis administrator can manage access. Compatibility sessions are directed to sign in, and historical reports never show live team controls. Product owners/consignors remain a separate roster locked at event opening.
