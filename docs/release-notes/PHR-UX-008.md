# PHR-UX-008 Release Note

Vendor Workspace now has one search across every loaded game catalogue. Finish-only duplicates collapse into one artwork result, each result identifies its game, and selecting a card exposes exact Finish before Condition so price evidence and buying decisions stay tied to the correct SKU.

Desktop remains the primary three-column card-show station; mobile is a one-column adaptation of the same workflow. This change is Product Review ready and is not yet canonically adopted, committed, pushed, deployed, or published.
