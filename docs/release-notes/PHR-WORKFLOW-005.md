# PHR-WORKFLOW-005 Release Notes

Phronesis Market Watch now stores exact card watches in the application database by user and workspace. Vendor Workspace can track a selected artwork, finish, condition, and language in one action, safely ignore duplicates, and undo a newly created watch.

Tracked prices refresh from verified Pricing Update Tool catalogue checkpoints. Existing browser watches migrate into an explicit legacy owner and remain locally available for rollback until identity activation and deliberate ownership claim.
