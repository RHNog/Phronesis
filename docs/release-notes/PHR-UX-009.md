# PHR-UX-009 Release Notes

The Snapshot Vendor Workspace now explains each ready buying recommendation through a visible Phronesis Intelligence panel. Operators can see the current Asset Assessment, evidence coverage, confidence, business conclusion, primary signals, opportunities, and risks without leaving the negotiation.

The established Intelligence Console is available through a compact disclosure for deeper model evidence. The panel reuses the existing purchase evaluation and does not introduce another score, formula, provider request, or recommendation path.

Desktop and 390px mobile layouts are verified without horizontal overflow. Riftbound remains deferred.
