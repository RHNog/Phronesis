# PHR-API-002 Release Note

Phronesis now supports provider-backed catalogue thumbnails through Magic/Scryfall, Pokémon/TCGdex, Lorcana/Lorcast, and the official Bandai English One Piece card list while keeping snapshot prices authoritative. One Piece variants resolve only through strict set, card-number, name, and variant evidence; Riftbound/Riot remains an explicit authorization-gated connection. Lorcana and Riftbound catalogue receipts are registered for automatic ingestion when the Pricing Update Tool produces them.

This change is Product Review ready and is not yet canonically adopted, committed, pushed, deployed, or published.
