# PHR-API-003 Release Notes

Market Watch can now retain three explicitly different evidence types: market estimates, active listings, and completed sales observed by the user. Saved evidence loads without provider calls, while official listing refresh is a deliberate action.

Official eBay Browse and CardTrader integrations are present but remain disabled without authorized server credentials. Optional JustTCG enrichment is disabled by default and request-budgeted. Phronesis does not scrape provider pages or present active listings as completed sales.
