# PHR-API-015 Release Notes

## 2026-08-05 — Maximum Liga Equivalence Coverage

Vendor Workspace can now present the broadest deterministic LigaMagic/LigaPokemon evidence available for each TCGplayer target. Every Magic and English Pokémon product receives an exact, compatible, ambiguous, or unavailable disposition. Compatible equivalents are visibly labelled and remain excluded from Arbitrage.

The release fixes encoded LigaPokemon identity fields, including Lucario V `27/73`: `Champion&rsquo;s Path` now resolves to the exact Champion's Path printing and exposes the acquired R$29.99 evidence. Pokémon single-card evidence coverage rises from the previous 25,200-target exact baseline to 32,600 exact-or-compatible targets without price-selected or fuzzy identity matching.

Sealed products and source-absent special products remain explicitly unavailable rather than receiving invented Liga identities or prices.
