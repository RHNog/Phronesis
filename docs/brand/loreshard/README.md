## Authority And Evidence Rules

1. The founder-supplied decision and domain-acquisition statements are recorded as internal facts for planning.
2. Prior search findings are historical **preliminary desk research**, not independently re-performed or legally validated by this documentation task.
3. Interpretations, positioning, visual direction, and module names are strategy recommendations, not registrations or launch approvals.
4. Counsel memoranda, filing receipts, domain registrar records, and namespace confirmations supersede preliminary statements when they become available.
5. A later change to the intended brand, legal recommendation, or launch status must update the Markdown and JSON records together.
