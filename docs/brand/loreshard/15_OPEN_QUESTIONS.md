# Open questions

These questions are intentionally unresolved. Do not infer approval from silence.

## Legal and ownership

- What legal entity should own applications, registrations, domains, and licenses?
- Is LORESHARD registrable in the U.S. and Brazil for the intended goods/services?
- Should Class 36 be included initially?
- What use, filing, symbol, disclaimer, and evidence strategy does counsel recommend?
- Which conflicting fantasy, software, data, or common-law uses materially affect adoption?

## Domains and namespaces

- Has control, renewal, and registrant information for both acquired domains been independently verified?
- Which defensive domains are worth acquiring, and when can that be done without premature disclosure?
- Which app-store, GitHub, npm, PyPI, Docker, and social namespaces are available?
- What fallback handle convention should be used if exact handles are fragmented?

## Brand and language

- How do U.S. and Brazilian target users pronounce, spell, and remember LoreShard?
- Does concept testing over-index on fantasy game items, crypto, or software infrastructure?
- Which identity territory balances collectible resonance and enterprise credibility?
- What trademark form and typography should be standardized?

## Product architecture

- Which proposed modules belong in the initial public suite?
- Should LoreShard API launch with the suite or remain partner-facing?
- Which proposed output names are commercially useful and legally viable?
- What proof is necessary before using “confidence,” “consensus,” or “value” terminology?

## Phronesis-to-LoreShard migration

- Which internal systems should permanently retain Phronesis?
- Which user-facing surfaces should become LoreShard?
- How will routes, packages, environments, telemetry, support, screenshots, and data migrations be sequenced and rolled back?
- How will dual-name confusion be prevented during a controlled transition?

## Launch

- What product-readiness threshold must be met?
- Is a private/password-protected pre-launch page useful after legal review?
- When should partners, employees, and testers be briefed?
- What exact evidence will the founder require before Gate 6 approval?
